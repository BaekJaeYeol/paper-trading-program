# 자동매매 GUI 안전성 개선 구현 계획

현재 구현: Tkinter `src/stockbot/gui.py`, Alpaca 모의계좌 전용 GUI, STOP 파일 신규 주문 차단. 토스 실주문은 차단 상태.

## 구현 순서
1. **P0 상태 배너**: 모의/실전, 시장, 브로커, 조회 시각, 갱신 실패를 각각 표시. 오류 후 오래된 계좌 값에는 '이전 조회' 표시.
2. **P0 주문 안전성**: 주문 계획/제출/접수/부분 체결/취소 요청/최종 취소/unknown 상태를 구분. 브로커 확인 없는 성공 메시지 금지.
3. **P0 STOP 및 재개**: STOP 파일 감지 상태와 브로커 주문 상태를 별도 표시. 재개 전 미확인 주문과 잔고 대조.
4. **P1 계좌 카드**: 금액의 통화·기준 시각, 평가/확정 손익 구분. 한국 KIS 조회 전용과 미국 Alpaca 모의매매 구분.
5. **P1 로그·오류**: 오류 유형 분류, 사용자 복구 행동 안내, API 키/계좌정보 마스킹.
6. **P1 접근성**: 키보드 포커스, 대비, 텍스트 상태, 창 축소 시 버튼 가림 점검.

## 수용 기준
- API 타임아웃 시 '주문 실패 확정' 대신 상태 미확인/브로커 확인 안내.
- STOP 실행 시 기존 주문 취소/포지션 청산이 되었다고 표시하지 않음.
- 계좌 조회 실패 시 마지막 값에 갱신 실패 및 시각을 표시.
- 실계좌 주문 API는 새로 연결하거나 활성화하지 않음.
- 네트워크 요청은 Tkinter UI 스레드를 차단하지 않음.
- Windows 11에서 940x620 및 일반 화면 배율에서 주요 기능 접근 가능.

## 검증
- 가짜 브로커로 정상/부분체결/타임아웃/취소 경합/재시작 불일치 테스트.
- GUI 키보드·창 크기·오류 문구 수동 점검.
- 구현 및 테스트 완료 전에는 상태를 '계획'으로 유지.
