# Alpaca 장기 일봉 읽기 전용 전략 연구

## 목적과 사용

적용한 모의 진입 필터를 장기 가격 이력으로 비교할 수 있는 데이터 입력 경로다.
개발 작업 중 실제 API 키로 조회하거나 실제 수익 개선을 검증한 것은 아니다.

GUI: 자동 실행 중지 → 미국 Alpaca 선택 → `백테스트` 탭 → `Alpaca 일봉 비교` → 종목 확인 → `조회·비교`.
기존 `API 연결`에서 설정한 모의 키/환경변수를 사용하며 키·원문 응답을 파일에 저장하지 않는다.
창의 취소는 API 요청을 시작하지 않는다. 조회 중 비상 중단 시 진행 중 요청이 돌아온 뒤 취소를 확인한다.

CLI:

```powershell
python -m stockbot.cli research-api --config config.json --symbol AAPL --capital 10000 --fee-bps 10 --slippage-bps 10 --sell-tax-bps 0
```

종목 생략 시 설정의 첫 종목을 사용한다. `--execute-paper`는 거부한다.
원금/비용/세금은 연구 가정이며 실제 계좌 잔고·요금·세율이 아니다.
결과는 JSON으로 출력한다. 설정·STOP·주문 DB를 수정하거나 주문을 제출하지 않는다.

## 데이터 계약

- 조회는 `/v2/clock`, `/v2/calendar`, 데이터 API의 `/v2/stocks/{symbol}/bars` GET만 사용한다.
- 브로커 시계의 미국 뉴욕 날짜를 기준으로 전날까지의 거래일만 사용한다. 당일은 장 마감 뒤에도 제외한다.
- 최근 약 3년(1096일)을 요청하며 `1Day`, `feed=iex`, `adjustment=split`, 오름차순을 명시한다.
- 모든 페이지를 최대 10개까지 읽는다. 페이지 토큰 반복/잘못된 토큰/5000봉 초과를 거부한다.
- OHLCV와 시간대, 날짜 순서/중복, 마지막 완료 거래일을 확인한다.
- 실제 첫 관측일부터 마지막 완료 거래일까지 거래일 달력과 날짜 배열이 일치해야 한다. 중간 누락/비거래일 봉은 실패한다.
- 상장 전 등 앞쪽 이력이 없을 수 있어 실제 시작일과 요청 시작일을 따로 기록한다. 전체 3년 이력을 보장하지 않는다.
- 300봉 미만이나 마지막 거래일 데이터가 없으면 보고서를 만들지 않는다. 누락 봉을 임의 생성하지 않는다.

전체 조회·비교 단계에서 60초 시간 제한과 취소를 체크한다. HTTP/CPU 작업을 강제로 선점하지 않으므로 정확히 60초 안에 반환한다는 보장은 아니다.
전송 실패는 고정 문구로 바꾸며 키/헤더/오류 원문을 노출하지 않는다. 재시도·유료 데이터 전환은 하지 않는다.

## 출처 표시와 해석

보고서는 `data_provenance=alpaca_iex_split_only`와 provider/symbol/feed/조정 방식/실제 시작일/마지막 완료 거래일/페이지 수/범위 밖 제외 봉 수를 포함한다.
화면에도 Alpaca/IEX, 분할 조정, 배당 미반영과 마지막 완료 거래일을 표시한다.
거래일 검사 통과는 가격 정확성·투자 성과·기업행위 처리 전체의 검증을 의미하지 않는다.

IEX는 SIP 전체 시장 데이터와 다르며 거래량 기준의 결과도 데이터 공급원에 영향을 받는다.
배당, 상장폐지 종목을 포함한 생존자 편향, 세금/환전, 실제 장중 지정가/브래킷 체결은 재현하지 않는다.
주식분할로 과거 조정값이 바뀌면 같은 기간을 다시 조회해도 데이터 SHA-256이 달라질 수 있다. 원문 캐시는 저장하지 않는다.
연구 후보는 자동 적용하지 않으며 실계좌 주문은 계속 비활성화 상태다.
실제 시장 성과 개선은 아직 미검증이다.

## 검증 범위

단위 테스트: 페이지 합치기, GET 경로만 호출, 출처 기록, 당일 제외, 거래일 누락/중복/마지막 누락,
데이터 부족, 토큰 반복/페이지 한도, 시간대/종목 오류, 취소/시간 초과 후 후속 조회 없음, 오류 원문 비노출,
CLI의 무주문/무상태쓰기와 execute 플래그 거부.
Windows GUI CI는 실제 데이터 선택 창과 비교 보고서를 오프라인 API 어댑터로 검증한다.
이때 보고서에 `합성 API 테스트 자료`를 명시하며 실제 서버/실제 시장 성과 검증으로 보고하지 않는다.
실제 사용자 키, 사용자 PC, 데이터 권한과 장기간 실제 거래 검증은 별도 필요하다.

기존 백테스트 버튼 줄에 읽기 전용 조회 버튼과 종목 확인 창을 추가하는 설계다.
Figma 도구 한도로 증분 화면은 본 문서에 명세했으며 Figma에 추가하지 못했다.
