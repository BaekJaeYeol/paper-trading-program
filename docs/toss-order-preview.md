# 토스 1만 원 주문 미리보기

## 범위와 화면 흐름

기존 `python -m stockbot.toss_gui` 실행 → `1만 원 주문 미리보기 · 전송 없음` →
미국 티커, 지정가(USD), 정수 수량 입력 → `예산 계산 · 실제 주문 없음`.
매수 후보는 사용자가 입력하며 자동 선정이나 추천이 아니다. 총 한도는 10,000원으로 고정한다.
실행 가능한 주문 payload나 승인 토큰을 만들지 않는다. 동일 화면을 반복 계산해도 주문·환전·예산 예약은 없다.
원화 현금 자동 환전이나 소수점 매수는 지원하지 않는다. 1주 비용이 한도를 넘으면 차단한다.

미리보기 모달은 입력 → 조회 중 → 비용 결과/차단/조회 실패 → 닫기로 구성한다.
조회 중 입력·계산·메인 새로고침을 차단한다. 닫으면 진행 중 읽기는 끝날 수 있으나 전송은 없다.
모든 결과는 조회 시점의 단일 추정이다. 숫자 입력을 바꾸거나 나중에 다시 판단하려면 재계산한다.
원본 계좌 정보·인증정보·원본 예외는 저장하지 않는다.
Figma 쓰기 한도로 이번 화면도 실제 Figma 파일 작성은 생략했다.

## 비용 및 계좌 검사

공식 OpenAPI v1.2.24 (2026-10-25 확인):
https://openapi.tossinvest.com/openapi-docs/latest/openapi.json

- 기존 계좌 snapshot을 계산 전후 조회하고 계좌 동일성 및 후보 보유 여부를 검사한다.
- 모든 기존 보유분은 관리 대상 아님이다. 후보가 기존 보유분과 같으면 미리보기를 차단한다.
- 일반 미체결 주문이 한 건이라도 있으면 차단한다. 자동으로 취소하거나 잔액에 중복 차감하지 않는다.
- 조건주문 OPEN 목록도 전후 확인하고 한 건이라도 있거나 페이지가 불완전하면 차단한다.
- STOCK/보통주/ACTIVE/USD/NYSE·NASDAQ·AMEX만 지원한다. 거래정지 및 세션 적격성 전체 검사는 아직 없다.
- 현재가 timestamp는 완료 시점 기준 0~60초, 환율은 validFrom 이상 validUntil 미만이어야 한다.
- 환율은 USD→KRW 참고 표시 환율이다. 실제 거래 환율을 보장하지 않는다.
- KST 날짜 기준 유효한 미국 수수료율 하나만 허용한다. 만료·중복·누락이면 차단한다.
- Decimal로 지정가×수량, 수수료를 계산하고 수수료는 센트 올림한다. 할인·면제는 보수적으로 미반영한다.
- 매수 비용에 환율 여유 1%를 더한 원화 추정액이 10,000원 이하여야 한다.
- USD 현금 매수 가능 금액으로 매수금액+수수료가 충당되어야 한다.
- 조회 전체는 30초 예산이며 요청 후에도 확인한다. 각 기존 urllib 호출은 최대 20초이므로
  30초 정각에 네트워크를 강제 중단하는 보장은 없다. 예산이 지난 결과는 폐기한다.

이번 검사는 단일 수동 매수 비용 검사다. 매도 비용·세금, 호가/유동성, 거래정지, 시장 세션,
동시 수동 주문, 실시간 계좌 변동, 전체 포지션 예산 관리와 전략 근거는 별도 구현 대상이다.
예산 검사 통과는 주문 가능/체결/안전성 승인/투자 수익을 뜻하지 않는다.

## 검증

오프라인 fixture로 정상 계산, 소수 비용 올림, 1만원 초과, 달러 부족, 잘못된 입력,
보유분 제외, 미체결/조건주문/페이지 미완성 차단, 시세·환율·수수료 만료,
통화/종목 불일치, 조회 중 계좌·주문 변경, 시간 예산을 검사한다.
네이티브 표시 환경에서는 실제 Tk 창 열기·입력·계산·읽기 전용 결과·닫기 테스트를 수행한다.
이는 fixture 기반 위젯 테스트이며 사용자 Windows 11의 실제 계좌 및 마우스 접근성 검증을 대체하지 않는다.
기존 Windows GUI 자동화는 기존 Alpaca 화면을 검사하며 토스 새 화면 전체를 포함하지 않는다.
실제 주문 전송은 `TossReadOnly.submit/cancel`에서 계속 차단된다.
