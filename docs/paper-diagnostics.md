# 모의계좌 진단 요약 내보내기

## 사용 흐름

1. 미국 Alpaca 모의 환경에서 `계좌·주문 대조`를 실행한다.
2. `차단 상세` 탭의 `진단 요약 저장`을 누른다. 키보드 Tab으로도 버튼에 접근할 수 있다.
3. 설정 파일과 상태 폴더 밖의 `.json` 경로를 선택한다. 취소하면 아무 파일도 저장하지 않는다.

보고서는 마지막 대조의 집계 정보만 사용한다. 추가 API 요청, 주문, 취소, 청산, 재개나 STOP 변경을 하지 않는다.
대조 작업 중에는 저장을 거부하며, 대조 전 또는 시장 전환 후에는 새 미국 모의계좌 대조를 요구한다.

## 데이터 계약과 개인정보

스키마: `paper-diagnostics-v1`. 성공한 전체 대조 소요 시간은 `reconciliation.elapsed_seconds` 정수로 제공한다. 생성 시각은 KST이며, 마지막 대조 수신 이후 경과 초를 포함한다.
60초 이상 경과했거나 이후 작업/조회가 실패하면 `stale=true`로 표시한다.
`inventory.ready_at_snapshot`은 당시 결과이며 현재 주문 권한/재개 승인이 아니다.
현재 GUI의 실행 여부와 STOP 요청 상태를 별도로 기록한다. Windows 절전 방지의 지원/요청 여부와 고정된 실패 코드도 포함한다.

내보내는 필드는 사전에 지정한 숫자·불리언·고정 코드·고정 안내 문구뿐이다.
API 키, 계좌 번호/지문, 주문 ID, 종목, 수량/금액 원문, 로그, 오류 원문, 설정, 파일 경로는 포함하지 않는다.
차단 사유별 집계는 화면에 제공되는 최대 200건에서 계산하며 전체 활성 수는 별도 `active_total`이다.
이는 전체 거래 감사 로그나 수익률/세금 보고서가 아니다.

같은 폴더에 임시 JSON을 완성한 후 교체한다. 쓰기 실패 시 기존 대상 파일을 보존한다.
설정 파일 자체와 상태 폴더의 파일은 GUI에서 대상 경로로 지정할 수 없다.
사용자가 선택한 기존 JSON 보고서는 저장 대화상자 확인 후 교체할 수 있다.

## 설계 및 검증

기존 차단 상세 화면의 목록 위에 저장 버튼 하나를 추가했다. 모달 저장 창과 성공/실패 안내를 사용한다.
Figma Starter 도구 한도 때문에 이번 증분 화면은 Figma에 추가하지 못했으며 이 문서로 동작/상태를 명세한다.
단위 검증: 중첩 민감 필드 제외, 잘못된 건수 거부, 지연/실패 표시, 원자적 저장 실패, 취소와 보호 경로, STOP 비변경.
Windows GUI CI: 실제 저장 대화상자에서 보고서를 저장하고 JSON 집계/민감정보 제외/실행 비변경을 확인한다.
실제 증권사 연결과 사용자 PC에서의 실행은 별도 검증 대상이다. 실계좌 주문은 비활성화 상태다.
