# 토스 실계좌 조회 화면

실행: 인증정보를 입력했던 PowerShell에서 `python -m stockbot.toss_gui`.

별도 창에서 보유종목, 원본 소수 수량, 거래 통화, 평균 매수가와 현재가,
일반 미체결 주문 건수, 조회 완료 시각(KST), 결과 경과 시간을 표시한다.
원본 API의 시세 발생 시각을 보장하는 실시간 화면은 아니다.
모든 보유분은 관리 대상 아님이다. 주문 엔진·Alpaca GUI·상태 DB와 연결하지 않는다.
실제 주문/취소, 자동 갱신, 매도 대상 등록, 계좌 전체 자산 합산은 미구현이다.

조회는 별도 스레드에서 수행하며 중복 클릭을 차단한다. 실패하면 이전 보유 목록을
숨기고 오류 상태를 표시한다. 계좌 번호, 인증정보, 원본 예외를 출력하거나 저장하지 않는다.
환경변수는 기존 조회 CLI와 동일하다. 여러 계좌는 TOSS_ACCOUNT_SEQ를 명시한다.
조회 범위는 국내/미국 주식이며 조건주문·옵션·채권을 포함하지 않는다.

공식 스키마: https://openapi.tossinvest.com/openapi-docs/latest/openapi.json
2026-10-25 확인 v1.2.24: HoldingsItem의 quantity/averagePurchasePrice/lastPrice는 decimal 문자열.

Figma 쓰기 한도 때문에 이번 독립 조회 화면의 Figma 파일은 제작하지 않았다.
기존 매매 화면에 브로커를 혼합하는 대신 별도 조회 창으로 설계했다.
실계좌 조회 CLI 성공은 사용자 화면으로 확인했지만 이 새 화면의 실제 계좌 및
사용자 Windows 11 실행은 별도 확인이 필요하다. 실거래 자동매매 완성으로 간주하지 않는다.
