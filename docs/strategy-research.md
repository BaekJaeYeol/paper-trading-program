# 비용과 시간 분리를 적용한 전략 연구

## 현재 전략의 약점과 연구 후보

실행 엔진은 이전 거래일의 거래량/30거래일 평균이 기준 이상이고, 21거래일 수익률이 상한 이하이면 후보로 본다.
수익률 하한이나 상승 추세 조건이 없어 큰 하락도 조건을 만족할 수 있다.
이 조건만으로 진입의 유리함이나 수익성을 입증하지 못한다.

이번 연구는 다음 고정 후보 5개를 비교한다. 효과가 검증된 매매법이라는 뜻은 아니다.

| 후보 | 연구 조건 |
|---|---|
| baseline | 현재 설정의 기존 신호 |
| trend_guard | 종가 >= 20일 평균 > 60일 평균, 21일 수익률 >= -10% |
| trend_volume_2 | 위 추세 조건 + 거래량 배수 2 |
| trend_volume_4 | 위 추세 조건 + 거래량 배수 4 |
| trend_volatility_guard | 위 추세 조건 + 14일 평균 True Range / 종가 <= 5% |

추세/변동성 조건은 오직 연구 백테스트에 전달한다. 기존 자동매매 신호·종목·주문 설정은 변경하지 않는다.
후보와 임계값은 연구 가정이며 검증/최종 구간을 보고 조정하지 않는다.
RSI/MACD 지표를 무작정 늘리거나 수천 개 조합을 탐색하지 않는다.

## 시간 분리와 선정 규칙

날짜가 증가하는 단일 종목 일봉 CSV 300~5000개를 받는다.
처음 60개 봉은 공통 워밍업이다. 전체 앞 60% 구간에서 워밍업을 제외해 학습하고, 다음 20%에서 검증, 마지막 20%에서 최종 평가한다.
날짜 순서를 섞지 않는다. 신호와 필터는 매수일 이전 봉만 받는다.
후보 선택은 학습 구간의 `비용 차감 수익률 - 최대낙폭` 점수만 사용한다. 같은 점수는 고정 후보 순서를 유지한다.
학습 청산 거래 5건 미만 후보는 선정하지 않는다. 검증/최종 각각 3건 미만이면 표본 부족을 표시한다.
이 기준은 통계적 유의성이나 실전 적합성을 보장하지 않는다. 반복 실행으로 최종 구간을 튜닝하면 과최적화될 수 있다.

기간마다 같은 임의 연구 원금과 무보유로 새로 시작한다. 이전 구간의 가격 봉은 지표 워밍업에만 사용한다.
각 기간 끝에 마지막 종가에서 강제 청산하고 비용을 차감한다. 기간별 수익률을 실제 포트폴리오처럼 연결하지 않는다.

## 비용, 회계와 비교

기본 가정은 매수/매도 각각 수수료 10bps(0.10%)와 슬리피지 10bps(0.10%), 매도세 0bps다.
실제 브로커 요금/세율이 아니며 CLI로 입력값을 바꿀 수 있다. 환전·배당·차입이자·세금 확정 처리는 없다.
원금은 CSV 가격과 같은 단위이며 기본 10,000은 실제 계좌 잔고나 10,000원 예산을 의미하지 않는다.
정수주만 계산하므로 원금/배분이 작으면 거래가 0건일 수 있다.

백테스트는 익일 시가 진입을 근사한다. 같은 봉에서 손절/익절이 모두 닿으면 손절을 먼저 처리한다.
갭과 슬리피지 후 진입가가 손절~익절 사이에 없으면 진입하지 않는다.
최대낙폭은 최초 원금과 일별 종가 평가액을 기준으로 계산하며 봉 중의 전체 낙폭을 재현하지 않는다. 승률/손익비는 청산 후 비용을 반영한 손익을 사용한다.
손실 거래가 없을 때 profit_factor는 무한대 대신 null이다.

순수익률·최대낙폭·청산 거래 수·승률·profit factor·가정 비용·노출일 수를 제공한다.
현금 0%와 같은 비중 단순 보유, 전액 단순 보유를 같은 기간/비용으로 함께 보여준다.
일봉 간격·배당·기업행위와 실제 수익 이력이 확인되지 않아 Sharpe/CAGR를 확정 성과로 제시하지 않는다.

실제 프로그램의 장중 지정가·브래킷·부분 체결·호가 대기열을 그대로 재현하는 백테스트가 아니다.
이 보고서가 실행 엔진의 수익률이나 승률을 예측한다고 해석하지 않는다.

## 사용법

GUI: 자동 실행을 중단한 뒤 `백테스트` 탭 → `전략 비교 (연구용)` → CSV 선택.
표와 비교 지표는 별도의 읽기 전용 창에 표시하며 자동 적용/주문 버튼은 없다. 취소는 작업을 시작하지 않는다.
연구 입력 오류는 계좌 연결 실패로 표시하지 않는다.

CLI:

```powershell
python -m stockbot.cli research --config config.json --csv historical_daily.csv --capital 10000 --fee-bps 10 --slippage-bps 10 --sell-tax-bps 0
```

CSV 열은 `date,open,high,low,close,volume`이다. `--execute-paper`는 거부한다.
결과는 JSON으로 출력하고 설정/상태/계좌에는 쓰지 않는다. 입력 가격 데이터의 SHA-256으로 재현 시 비교할 수 있다.
GUI의 연구 원금/비용은 위 기본 연구 가정이다. 다른 가정은 CLI에서 비교한다.

## 데이터와 검증 범위

현재 제공된 examples/demo.csv는 합성 65개 봉이므로 연구 입력 최소 기준에 못 미친다.
출처, 수정주가/배당/분할, 생존자 편향, 거래소 영업일, 실제 체결 비용이 검증된 장기 데이터가 아직 없다.
모든 CSV는 `unverified_csv`로 표시하며 어떤 후보도 실전 승인/자동 적용하지 않는다.
실제 시장 수익 개선을 입증하지 않았다. 다종목·다기간·체결 비용 스트레스 검증은 후속 작업이다.

단위 테스트는 미래 검증 데이터 변경 시 학습 선정 불변, 비용/손절 순서/최종 청산, 입력 검증,
비거래 후보 제외, 추세/변동성 필터, 같은 비중 보유 비교, CLI 무주문/무상태쓰기, GUI 취소/오류를 확인한다.
Windows GUI CI는 별도 합성 360개 봉으로 읽기 전용 비교 창과 브로커 호출/설정 변경 없음을 확인한다.
이는 실제 시장 백테스트 결과가 아니다.

UI는 기존 백테스트 탭의 연구 버튼과 읽기 전용 비교 창을 사용한다.
Figma 도구 한도로 이번 증분 화면은 문서로 명세했으며 Figma 추가 반영은 하지 못했다.
