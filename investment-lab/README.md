# 투자랩 v0.1 — 과거 검증과 일봉 모의투자

Windows Python 3.11+용 데스크톱 연구 프로그램입니다. 실제 과거 가격으로 5개 신호와 20개 두 신호 조합을 비교하고, 선정 후보를 고정한 로컬 가상계좌로 새 거래일을 추적합니다.

## Windows 실행

1. Python 설치 시 Tcl/Tk 및 Python Launcher를 포함하세요.
2. 압축을 풀고 `install.bat`를 실행합니다. Windows 시간대 데이터 설치입니다.
3. `start.bat`를 실행합니다.
4. 종목(예: SPY)을 입력 → 실제 데이터 수집 → 전략 비교 실행.
5. 모의계좌 탭 → 선정 후보로 시작. 가상 $10,000 계좌이며 실제 돈이 움직이지 않습니다.

데이터 수집이 제한되면 CSV 가져오기를 사용하세요. GUI에서 제공 출처를 확인할 수 없는 CSV는 ‘출처 미확인’으로 표시하고 모의계좌 시작에는 사용하지 않습니다. 합성 데모는 키와 네트워크 없이 비교 화면을 시험하는 용도입니다.

## 구현

- 실제 다운로드: Yahoo 일봉 5년, 당일 일봉 제외. 타임아웃 및 HTTP 실패 표시, 검증 후 데이터 저장, SHA256와 출처 기록.
- 추세(20/60 평균), 모멘텀(60일), 돌파(이전 20일 최고 종가), 평균회귀(20일 평균 - 1 표준편차), 거래량(이전 30일 대비 3배·21일 수익률 3% 이하).
- 개별 신호와 두 신호 AND / 각 50% 자금 배분 비교.
- 초기 준비 구간 제외 뒤 개발 50% / 검증 25% / 보류 25%. 검증 Sharpe 기준, 회전량 4 이상 후보만 선정. 없으면 현금.
- 마지막 구간에는 현금·매수 후 보유·선정 후보만 평가. 비용 2배 민감도 결과 포함.
- 소수점 비중, 다음 일봉 시가 재배분. 백테스트 기본 편도 비용 0.2%(수수료 0.1%+슬리피지 0.1%). 마지막 종가 청산 비용 포함.
- 모의계좌: 시작 당시 최신 완료 일봉 이후만 처리, SQLite 원자적 잔고/거래 기록, 날짜 중복 방지, 재시작 재개, 기준 가격 수정 감지.
- 모의 운영 5분마다 조회하지만 새 완료 일봉이 생겼을 때만 처리. 이는 일봉 전진 검증이며 실시간 호가 체결 시뮬레이션이 아닙니다.

`workspace/reports`에 실험별 `metrics.csv`와 `summary.json`, 당시 입력 CSV 사본이 저장됩니다. 데이터 출처·해시·기간·비용·선정 기준을 추적합니다. `workspace/paper`에는 종목별 모의계좌, `workspace/data`에는 다운로드 데이터를 저장합니다. 동일 종목의 계좌가 있으면 기존 고정 전략으로 재개합니다. 앱에서 초기화/삭제하지 않습니다.

공개 과거 GOOG 표본(2004-08-19~2013-03-01)을 이용한 최초 실행 결과는 `historical_check`에 있습니다. 마지막 보류 구간 추세 전략 -6.76%, 매수 후 보유 +31.42%. 단일 과거 표본이며 전략 수익성 입증이 아닙니다. `examples/GOOG_historical.csv`의 가격 조정 기준은 독립 확인하지 않았습니다.

## 범위와 제한

실계좌 및 증권사 주문 API가 없는 로컬 연구 도구입니다. 기존 저장소의 Alpaca 모의주문 프로그램과 별도이며 선정 전략을 그 주문 경로에 자동 연결하지 않습니다. 실제 시세가 사용되더라도 부분 체결·호가·시장 충격·지정가 미체결을 재현하지 않습니다. 당일 완료 봉도 다음 날짜부터 사용하므로 약 하루 지연됩니다.

과거 수정주가/배당/상장폐지/당시 종목 유니버스 검증은 추가 작업입니다. Yahoo 데이터 품질·이용권은 제공자 조건에 따릅니다. 여러 종목 계좌는 각각 $10,000의 독립 실험이며 합산 포트폴리오가 아닙니다. 백테스트는 비용을 비중에서 차감하고 전진 모의는 체결가에 슬리피지를 적용하므로 미세한 수치 차이가 있습니다. 모든 조건에서 수익을 보장하지 않으며 프로그램은 실거래 적합 판정을 하지 않습니다.

운영 중단은 새 갱신을 멈추고 보유분은 유지합니다. 이미 진행 중인 다운로드/원자적 일봉 처리 한 회는 완료될 수 있습니다. 중단 기간의 새 일봉은 재개 때 처리하므로 그 기간은 사후 재생입니다. 실제 미래 관찰과 구분하세요. 전진 모의 누적 운영일에 따른 자동 통과 조건은 아직 없습니다.

## Google Drive 자동 저장

1. Windows에 Google Drive 데스크톱 앱을 설치하고 로그인합니다.
2. 내 드라이브에 `투자랩_결과` 폴더를 만듭니다.
3. 앱의 **Google Drive 자동 저장** 탭에서 PC에 보이는 해당 폴더를 선택합니다.
4. **검증 완료 · 모의계좌 갱신 후 자동 저장**을 켭니다.

검증 결과와 모의계좌 전체 거래 기록을 JSON으로 자동 저장합니다. 결과 내용이 같으면 동일 파일을 재사용합니다. 원본 시세 CSV, SQLite, 인증 정보는 내보내지 않습니다. 폴더가 끊기면 workspace/drive_outbox에 대기하며 다음 저장 또는 재시도 버튼으로 처리합니다. 저장 오류가 모의 운영을 중단하지 않습니다. 설정은 PC의 workspace에 보존됩니다. 앱과 Drive 데스크톱 앱이 실행 중이어야 합니다.

**동기화 폴더 저장 완료는 클라우드 업로드 완료가 아닙니다.** 로그인·네트워크·Drive 동기화 상태를 직접 확인하세요. 이 앱은 Drive API 인증을 구현하지 않았으며, 클라우드 업로드 확인과 ChatGPT 자동 분석 기능은 없습니다. ChatGPT에 연결한 Google 계정과 PC의 Drive 계정은 별도로 설정합니다. 계정 변경 전 대기 기록을 확인하세요. 선택한 폴더의 기존 공유 권한이 내보낸 기록에도 적용될 수 있습니다.

참고: https://support.google.com/drive/answer/13401938?hl=ko
설계 비교: Google 공식 Python Drive API 샘플은 별도 OAuth 앱 구성이 필요하므로, 이번 버전은 데스크톱 동기화 폴더를 사용합니다. https://github.com/googleworkspace/python-samples/tree/main/drive

추가 검증: 연결 끊김 대기/재시도, 중복 방지, 내보내기 필드 제한, 전체 거래 기록 내보내기 테스트. 실제 사용자 PC의 Drive 클라우드 동기화는 미검증입니다.

### 용량 관리: 최신 결과 + 월별 압축 보관

자동 저장 시 종목·출처·계좌 포함 여부별 최신 JSON을 유지하고, 모든 변경 기록은 `investment-lab-history-YYYY-MM.zip`에 압축 보관합니다. 월 기준은 서울 시간의 저장 시각입니다. 기존 해시 이름의 결과 파일도 다음 저장/재시도 때 자동 정리합니다. 압축 내용을 검증한 뒤 개별 과거 JSON을 제거하며, 기존 보관 파일이 손상되면 원본을 유지합니다. 다른 이름의 사용자 파일은 건드리지 않습니다. 같은 월의 같은 내용은 중복 보관하지 않습니다.

ZIP에도 최신 시점 기록을 포함하므로 복구에 사용할 수 있습니다. 최신 JSON은 ChatGPT에 전달하기 편하게 별도로 남깁니다. 월별 ZIP은 자동 삭제하지 않으므로 장기적으로 용량은 증가합니다. PC의 연구 원본과 모의계좌 DB는 이 기능으로 정리하지 않습니다. 실제 Drive 클라우드 동기화 완료 여부는 여전히 확인하지 않습니다.

참고 구조: 월별 보관/회전 정책 https://github.com/shello/gfs.py (정책 비교용, 코드 복사 없음). 이번 구현은 기록을 삭제하지 않는 월별 ZIP 보관을 사용합니다.

### 모의 운영 상태 확인

모의계좌 탭에 종목/보유 수량, 최근 모의 매수·매도 날짜·수량·체결 가정 가격·수수료를 표시합니다. 거래표의 buy/sell/hold는 모의 매수/모의 매도/유지로 표시합니다. 최신 매매는 화면의 최근 100행 밖에 있어도 계좌 DB에서 조회합니다.

갱신 중에는 데이터 확인 중, 성공하면 서울 시간의 최근 갱신 성공 시각과 새 일봉 처리 개수 또는 새 데이터 없음을 표시합니다. 실패하면 실패 시각·최근 성공 시각·오류를 표시하고 기존처럼 운영을 중단합니다. 성공 시각은 앱 실행 중에만 유지하며 재시작 시 첫 갱신 대기로 표시합니다. 마지막 처리일은 시세 날짜이고 갱신 성공 시각은 다운로드 및 처리가 완료된 시각으로 서로 다릅니다. 새 일봉이 없으면 거래표는 변하지 않습니다. 현재 선택 종목 하나의 모의계좌이며 자동 종목 탐색 기능은 없습니다.

### 시작 즉시 신호 적용

시작/재개 버튼을 누르면 계좌별 최초 1회에 한해 최신 완료 일봉의 고정 전략 신호를 조회 가격에 적용합니다. 매수 비중 신호가 있으면 현재 보유분과 현금을 반영해 모의 매수/매도하고, 신호가 없으면 유지로 기록합니다. 무조건 매수하지 않습니다. 기존 계좌에도 최초 1회 적용할 수 있지만 마지막 처리일과 현재 입력 일봉이 일치해야 합니다. 이미 시작 시 신호를 적용한 계좌는 재시작해도 재체결하지 않습니다.

가격은 Yahoo의 최신 분봉 종가이며 실제 실시간 호가가 아닙니다. 프리마켓/정규장/애프터마켓을 구분하고 지연 가능성을 표시합니다. USD/종목/가격/시간을 확인하고 20분 이상 오래된 가격, 확인 불가능한 세션, 조회 오류에는 즉시 체결하지 않습니다. 신호용 완료 일봉이 7일보다 오래돼도 차단합니다. 휴장/장 마감 후에는 실행이 차단될 수 있습니다. 조회 가격에 기존 수수료·슬리피지를 적용합니다. 장외 유동성·스프레드·부분 체결은 모델링하지 않습니다.

시작 시 가상 체결일 일봉이 추후 들어오면 평가금액만 업데이트해 같은 날의 시가로 다시 거래하지 않습니다. 그 이후에는 기존 일봉 다음 시가 방식으로 운영합니다. 따라서 시작 시 체결 방식은 과거 검증의 다음 시가 방식과 다르며, 성과를 동일한 실행 조건으로 해석할 수 없습니다. 원본 모의계좌 DB를 유지하고 새 버전으로 재개하세요. 최초 체결 가격의 데이터 시각과 세션은 계좌 설정과 Drive 내보내기에 보존합니다.

테스트: 최초 매수/현금 유지, 재시작 중복 차단, 가격 검증, 시작 당일 중복 시가 체결 차단, 이후 일봉 운영. 실제 Yahoo 최신 가격 다운로드는 실행 환경 제한으로 미검증이며 사용자 PC에서 확인이 필요합니다.

## 확장 검증 (2026-10-10)
`확장 검증 · 병렬 계좌` 탭에서 쉼표로 최대 12종목을 입력하고 실제 데이터 반복 검증을 실행합니다. 이전 252거래일의 Sharpe/회전량으로 후보를 선정하고 이후 63거래일을 평가하며, 평가 구간은 겹치지 않습니다. 최소 376일이 필요합니다. CSV도 같은 방식으로 평가할 수 있으며 출처를 표시합니다. 결과는 workspace/batch_reports에 저장됩니다.

각 구간 시작 직전 60거래일 수익률로 상승(5% 초과), 하락(-5% 미만), 횡보를 구분하여 JSON에 기록합니다. 이는 단순 분석 기준이며 시장 상황 예측 기능이 아닙니다. 전체 고정 후보의 결과 비교는 탐색용이고, 최종 독립 보류 검증을 대체하지 않습니다. 종목 간 상관관계 때문에 결과 건수를 독립 표본 수로 해석하지 마세요.
