# 運用 보강 v2

1. `paper-hourly-state/intraday-state/README.md`에서 최근 확인·성공, 다음 예약 UTC, 종목 상태, v1/v2 전략별 평가액·손익과 최근 매매 이유를 확인한다. 전체 주문 기록 JSON으로 부분 체결·미체결 수량, 잔량 만료, 처리 시각과 가상 체결 시각을 확인한다. 예약은 실행 보장이 아니다.
2. exchange_calendars 4.12의 XNYS 정규장 달력으로 휴일·조기 폐장·서머타임을 처리한다. 최신 기대 봉 종료 후 20분 유예를 넘겨도 봉이 부족하면 갱신을 멈추고 기존 계좌를 보존한다. 미래의 임시 휴장과 공급자 오류는 별도 점검이 필요하다. 현재 종목은 미국 ETF만 지원한다.
3. v1 SQLite 계좌는 유지한다. v2 `accounts-v2.json`은 처음 확인한 마지막 봉에서 $10,000 현금으로 시작한다. 직전 완료 봉 신호→다음 봉 시가, 편도 수수료 0.1%, 슬리피지 0.1%, 반 스프레드 0.01%, 직전 봉 거래량 1% 한도를 적용한다. 잔량은 해당 봉에서 만료하며 다음 봉은 새 목표로 재산정한다. 실제 호가를 재현하지 못하는 가정이다. 기록은 과거 가격 기반 시뮬레이션이며 실제 주문·체결이 아니다.

같은 시작일이 아닌 v1/v2 수익률 직접 비교는 금지한다. 기존 research.json의 과거 연구는 v1 단순 비용 모델이며 v2 실험 결과가 아니다. v2 효과는 같은 구간에서 별도로 측정해야 한다. 부분 체결과 데이터 지연을 모델링했다고 실거래 적합성이 입증되는 것은 아니다.

검증: 휴일, 조기 폐장, 서머타임, 지연/휴장 구분, 주말 예약 제외, 부분/미체결, 미래 봉 거래량 비참조, 중복 실행, 수정 가격 거부 및 기존 계좌 보존.
