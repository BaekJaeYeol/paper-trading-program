# 요구사항과 완료 범위

목표: 실제 과거 데이터에서 개별 신호 효과를 비교한 뒤 조합 후보를 선정하고, 이후 일봉 전진 모의로 관찰한다.

완료: 데이터 다운로드 경로·CSV·데모, 데이터 검증과 출처, 5개 전략·20개 조합, 시간 분리, 비용 민감도, 결과 저장, GUI 코드, 고정 전략 전진 모의, 중복 처리 방지와 원자적 저장, 재시작과 가격 수정 차단, 핵심 테스트.

검증: Windows CI에서 GUI 초기 실행/결과 표 표시 포함 테스트 8개 통과.

미검증: 신규 실데이터 다운로드(환경 제한), Windows GUI 직접 마우스/키보드 조작, 장기간 미래 모의 운영, 다중 종목 포트폴리오·현재 시장 수익성.

미구현: 증권사 모의주문 연동, AI·재무·뉴스 전략, 자동 실거래 승인.

설계: 상단 종목·수집·비교; 탭 전략 비교/모의계좌/안내. 표의 모든 수치는 출처·구간을 표시하고 실제 다운로드·출처 불명 CSV·합성을 구분한다. Figma 와이어프레임의 흐름을 Tkinter로 구현한다.

2026-10-08 추가: Google Drive 데스크톱 동기화 폴더 설정, 검증/계좌 갱신 자동 JSON 내보내기, 연결 단절 대기 및 수동 재시도, 전체 거래 기록, 출처 보존, 인증/원본 시세 제외. 클라우드 업로드 확인 및 ChatGPT 자동 분석은 별도 미구현. 원격 Drive에 실제 업로드했다는 판정은 하지 않음.

추가: 최신 JSON 유지 + 서울 시간 기준 월별 ZIP 자동 보관. 기존 결과 마이그레이션, 압축 내용 검증 후 개별 스냅샷 제거, 보관 손상 시 원본 유지, 오래된 대기 결과로 최신 결과 덮어쓰기 방지. 월별 ZIP 자동 삭제 없음.

Use Case — 모의 운영 확인: 시작/재개 → 첫 갱신 대기 → 데이터 확인 중 → 성공 시 시각 및 새 데이터 없음/처리 개수 표시. 실패 시 오류/최근 성공 시각 표시 및 운영 중단. 보유 종목·수량과 최근 모의 매수·매도는 별도 표시. 거래 유무와 다운로드 성공을 구분. Windows GUI 검증: 빈 기록/새 데이터 없음/신규 거래/수동 중단 후 콜백 상태 유지.

Use Case — 시작 즉시 모의체결: 실제 데이터 전략 고정 → 계좌 생성/조회 → 미적용 계좌만 최신 분봉 가격/세션/시간 확인 → 최신 완료 일봉 신호로 현금·수량 반영 → 비용 포함 가상 거래를 DB 트랜잭션으로 저장 → 최초 적용 플래그. 예외: 오래된 가격/일봉, 누락 세션, 통화/종목 불일치, 기준 가격 수정에는 미체결. 당일 일봉은 평가 갱신만, 이후 일봉은 기존 다음 시가 체결. 실시간 자동매매/증권사 주문 아님.

## 확장 검증 Use Case
- UC-V1: 종목 목록 입력 → 종목별 다운로드 → 이전 252일 후보 선정 → 다음 63일 평가 반복 → 표/JSON 저장. 일부 다운로드 실패는 종목별 오류로 표시하고 성공 종목은 계속 처리한다.
- UC-V2: 현재 CSV의 반복 검증. 출처 표시, 최소 376행 미달은 오류 기록. 각 평가 구간은 독립 가상 자금에서 시작한다.
- UC-V3: 실데이터 현재 종목으로 전략별 계좌 생성/재개 → 새 일봉만 순서대로 처리 → 잔고 표 표시 → 5분 갱신. 데이터 기준 변경/오류 시 중단. 계좌별 SQLite를 사용하여 기존 계좌와 분리한다.
- 후보는 고정하고 구간 선택에는 미래 정보를 사용하지 않는다. 시장 상황은 구간 시작 전 수익률만으로 분류한다.
- 검증: 미래 데이터 변경에도 첫 구간 선정 불변, 계좌 재시작 중복 없음, 현금/보유 전략 자금 분리, 부분 실패 지속.
