# 서버 장중 모의투자 10종목 확장

요청: PC 없이 운영하는 기존 모의투자에서 ETF 4종목을 유지하고 서로 다른 업종의 미국 개별주 6종목을 추가한다. 실제 증권사 주문과 KIS 연결은 변경하지 않는다.

- 기존: SPY, QQQ, IWM, DIA
- 추가: MSFT(소프트웨어), JPM(은행), XOM(에너지), JNJ(헬스케어), CAT(산업재), WMT(유통)
- 투자 추천·자동 우승 전략 선정이 아닌 고정 연구 목록이다. 이 목록만으로 전체 시장이나 생존자 편향을 해결하지 않는다.
- 종목별 27전략이며 v1과 v2 각각 270계좌다. 모델을 합치면 540개 독립 가상 계좌이며 하나의 실제 포트폴리오가 아니다.

## 처리와 예외
기존 ETF 원장을 보존한다. 새 종목은 첫 확인 때 초기 자금 $10,000으로 생성하고 다음 새 완료 정규장 15분봉부터 처리한다. 같은 봉 재실행은 중복 매매하지 않는다. 종목 하나의 수집·신선도·가격 수정 검사 실패는 해당 종목의 기존 계좌를 유지하고 다른 종목 처리를 계속한다. 실패가 있으면 작업 전체는 실패로 표시하되 성공한 종목 기록과 상태를 저장한다.

워크플로에서 `--symbols SPY QQQ IWM DIA MSFT JPM XOM JNJ CAT WMT`를 지정한다. 기본 실행은 기존 4종목이며 중복은 제거하고 최대 20종목까지 허용한다. 평일 UTC 매시 7·22·37·52분 예약, 거래소 달력과 v2 보호 기준을 유지한다. 예약 지연 및 데이터 제공 제한은 가능하다.

## 완료 검증
GitHub에서 10종목 수집, 종목당 27계좌, 계좌 보존과 중복 방지·비용·복구 기존 검사, 실제 생성 HTML의 Chromium 상호작용 검사를 확인한다. 새 계좌는 과거 거래를 채워 넣지 않으므로 기존 ETF와 시작일이 다르다. 실행 시간과 오류 기록을 보며 추가 확장 여부를 판단한다.
