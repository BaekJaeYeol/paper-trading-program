# 매매 근거 알고리즘 확장

## 범위와 사용 흐름

기존 27개 고정 전략에 서로 다른 근거를 사용하는 20개를 추가해 총47개로 비교합니다. 1차 확장37개에 이어 2차 확장10개를 더했습니다. 각 종목·전략·v1/v2는 별도 가상 계좌입니다. 10종목이면 모델별470개이며, 합계940개를 하나의 포트폴리오로 해석하지 않습니다. 자동 우승 전략 선택·최적화·실주문은 추가하지 않습니다.

정상 흐름: 완료 정규장 OHLCV → 기존 데이터 무결성 검사 → 지표·목표 비중 계산 → 직전 봉 근거를 다음 봉 시가 모의 체결에 연결 → 계좌·판단 근거 저장 → 읽기 전용 보고서 표시. 데이터 부족·변동폭0·거래량0에서는 관련 지표가 대기합니다. 기존 봉 누락·중요 가격 수정·계좌 오류는 해당 종목 갱신을 중단합니다.

기존 수집기·신호 계산기·Paper/v2 체결기·파일 저장소·HTML 보고서 구조를 유지합니다. 새 `extended_strategies.py`는 계산과 설명만 담당합니다. 기존 계좌는 초기화하지 않으며 신규 전략은 배포 시 마지막 완료 봉을 기준으로 현금10000달러에서 시작합니다. 과거 체결을 채워 넣지 않습니다. 시작일이 다른 계좌의 누적 손익을 직접 순위 매기지 않습니다.

## 고정 규칙

공통: 목표 비중은 매수·보유1 또는 현금0입니다. 회복 규칙은 충족한 한 봉의 목표이며 보유 상태를 유지하는 별도 진입·청산 시스템이 아닙니다. 다음 봉에 조건이 사라지면 목표는0으로 돌아가 비용이 늘어날 수 있습니다.

| 이름 | 목표1 조건 | 준비 기간 |
|---|---|---|
| ema_12_26 | EMA12 > EMA26 | 26봉 |
| macd_12_26_9 | EMA12−EMA26 > MACD의 EMA9, MACD > 0 | 34봉 |
| rsi_14_recovery | 직전 Wilder RSI14 <30, 현재 >=30 | 16봉 |
| bollinger_20_reentry | 직전 종가가 직전 SMA20−2σ 아래, 현재 종가는 현재 하단밴드~SMA20 | 21봉 |
| donchian_20 | 현재 종가 > 현재를 제외한 직전20봉 최고 고가 | 21봉 |
| atr_14_breakout | 종가 > 직전 종가+직전 Wilder ATR14, 종가 > EMA26 | 26봉 |
| session_vwap | 종가 > 뉴욕 거래일별 누적 전형가격 VWAP | 누적 거래량 >0 |
| obv_20 | OBV > OBV의 SMA20, 종가 > EMA26 | 26봉·최근20봉 거래량 >0 |
| stochastic_14_3_recovery | 직전 %K14 <20, 직전 K<=D이고 현재 K>D | 17봉·고저폭 >0 |
| mfi_14_recovery | 직전 MFI14 <20, 현재 >=20 | 16봉·14기간 자금흐름 >0 |

EMA는 기간 첫 SMA로 초기화합니다. RSI·ATR은 최초14개의 전일 변화/진폭 평균 뒤 Wilder 평활을 적용합니다. MFI는 전형가격=(고가+저가+종가)/3의 전봉 대비 방향과 전형가격×거래량을 사용합니다. 전형가격이 같으면 양·음 흐름 모두0입니다. 양·음 흐름이 모두0인 비율 지표는 중립50입니다. 볼린저 표준편차는 모집단 표준편차입니다. Stochastic은 raw %K14와 그 SMA3인 %D이며 slow stochastic과 구분합니다. VWAP은 봉의 전형가격 근사로 실제 틱 VWAP이 아닙니다. VWAP 이외 지표는 거래일을 넘어 이어지며, EMA/RSI/ATR은 다운로드된 이력 시작점에 영향을 받습니다.

## 근거와 저장 계약

각 종목의 `strategy-evidence.json`에 추가20개 전략의 최신 `signal_bar`, `target`, `rule`, `indicators`, `reason`을 저장합니다. v2 신규 이벤트에는 해당 **직전 신호 봉**의 `evidence`와 설명을 보존합니다. 보유·체결 보류·위험 중단 상태는 기존 체결기의 별도 필드가 우선합니다. 최신 조건 충족이 곧 주문 제출이나 체결을 의미하지 않습니다. 새 계좌의 화면에는 현재 판단 근거를, 이벤트가 있는 계좌에는 마지막 처리 근거를 표시합니다.

전략 목록·규칙 버전을 연구 캐시 키에 포함해 가격이 같아도 새 전략의 비용 비교를 계산합니다. 새 연구 결과의 기존 전략 수치는 원래 공통 구간을 유지합니다. 신호 행렬은 실행당 공유해 계좌마다 지표를 반복 계산하지 않습니다.

## 검증과 한계

EMA 초기값·단조 수열의 RSI/MFI/ATR, 돌파의 현재 봉 제외, 반등 전환, 미래 봉 추가 전후의 신호·설명 동일성, 거래량0·가격불변·초기 데이터 부족, VWAP 거래일 초기화를 검사합니다. 전략 확장 시 기존 계좌 보존·신규 계좌 현금 시작·비용 비교 캐시 갱신·중복 실행·다음 봉 이벤트의 직전 봉 근거를 통합 검사합니다.

참고 원본: [TA-Lib](https://github.com/TA-Lib/ta-lib), [지표 목록](https://ta-lib.org/functions/). 지표 개념을 참고한 독립 표준 라이브러리 구현이며 TA-Lib와 모든 값이 동일하다고 검증하지 않았습니다. TA-Lib를 실행 의존성으로 추가하지 않습니다. 지표 구현 검사는 수익성 입증이 아니며, 여러 전략을 살펴본 뒤 좋은 결과만 선택하면 과최적화 위험이 있습니다. 정해진 과거 구간 비용 비교와 신규 계좌의 향후 모의 기록을 구분해 평가해야 합니다.


## 2차 추가 10개 규칙

| 이름 | 목표1 조건 | 준비 기간 |
|---|---|---|
| adx_14_trend | Wilder ADX14 >=25, +DI14 > -DI14 | 28봉·ATR >0 |
| aroon_25_trend | Aroon Up >70, Down <30 | 26봉 |
| cci_20_momentum | 전형가격 CCI20 >100 | 20봉·평균절대편차 >0 |
| williams_14_recovery | 직전 %R14 <−80, 현재 >=−80 (한 봉 목표) | 15봉·현재/직전 고저폭 >0 |
| cmf_20_accumulation | CMF20 >0.1 | 20봉·20봉 거래량 >0 |
| chaikin_3_10 | ADL의 EMA3−EMA10 >0, 종가 >EMA26 | 26봉·최근20봉 거래량 >0 |
| roc_10_momentum | 10봉 종가 변화율 >1%, 종가 >EMA26 | 26봉 |
| trix_15_trend | 15봉 삼중EMA의 1봉 변화율 >0, 종가 >EMA26 | 44봉 |
| keltner_20_breakout | 종가 >EMA20+2×Wilder ATR14 | 20봉·ATR >0 |
| opening_range_30m | 뉴욕09:30·09:45 봉의 최고 고가를 10:00 이후 종가가 돌파 | 당일 첫2개 봉 모두 필요 |

ADX는 봉1~14의 방향 이동과 기존 Wilder ATR14를 사용하고, 첫14개 DX(봉14~27)의 평균으로 시작합니다. 이후 Wilder 평활합니다. Aroon은 현재를 포함한26개 봉에서 최근25기간의 극값 나이를 계산하며 고저가 동률은 가장 최근 봉을 선택합니다. CCI의 분모는 0.015×평균절대편차입니다. Williams %R은 −100~0의 raw14봉 범위를 사용합니다.

자금흐름 배수는 (2×종가−고가−저가)/(고가−저가)이며 고저가가 같으면0으로 둡니다. CMF는20봉의 배수×거래량 합을 거래량 합으로 나눕니다. ADL은 이를 누적하고 Chaikin은 ADL의 EMA3−EMA10입니다. TRIX의 각 EMA15는 유효한 첫15개 값의 SMA로 초기화합니다. Keltner는 EMA20 종가 중심선과 ATR14 배수2인 고정 정의이며 지표 라이브러리의 다른 기본 설정과 다를 수 있습니다.

장 초반 돌파는 뉴욕 시간대·서머타임을 따릅니다. 다운로드 이력이 장 중간부터 시작해09:30 또는09:45 봉이 없으면 그날은 대기합니다. 거래일마다 범위를 초기화하고 범위가 만들어진 두 봉 자체에서는 진입 신호를 내지 않습니다. 정규장 밖 데이터는 수집 단계에서 제외하며 규칙에서도 뉴욕16:00 이후를 제외합니다.

기존37개 신호와 계좌는 유지하며 새10개 계좌만 현금으로 시작합니다. 모든 추가20개 전략에 미래 봉을 붙이기 전후 신호·근거 일치, 가격불변·0거래량, 준비기간을 검사합니다. 2차 규칙은 ADX·Aroon·CMF 기준값, 고저가 동률, Williams 회복, 장초반 봉 누락·다음날 초기화·서머타임을 추가 검사합니다. 지표 간 상관관계가 있으므로47개를 독립적인 매매 근거47개로 해석하지 않습니다.
