# 제공처 과거 봉 수정 대응

2026-10-14 DIA·CAT 처리 중 기준 종가 변경을 발견했다. CAT의 2026-10-13 16:45 UTC 봉은 저장 종가 760.8599853515625, 다시 받은 종가 760.9450073242188이었다. 엄격한 동일 가격 검사 때문에 반복 중단됐다.

계좌·거래 원장 초기화 없이 이전에 수집한 완료 봉을 고정한다. 재수집한 과거 봉이 바뀌어도 저장 가격과 거래량을 사용하고 data-revisions.json에 수정 내역을 기록한다. 새 봉은 기존 검증을 거쳐 추가한다. 이 방식은 첫 수집 당시의 관측을 유지하는 전진 실험이며 제공처의 최신 수정 데이터를 반영한 연구 결과와 다를 수 있다.

현재 v2 계좌 중 가장 이른 last_date 이후 OHLC 수정이 0.5%를 넘으면 계속 중단한다. 0.5%는 운영상 보수적인 차단 기준이지 데이터 정확성·기업행사 판정 기준이 아니다. 그 이전 연구용 봉은 수정 크기와 관계없이 저장 원본을 유지하고 수정 이력만 남긴다. 실제 분할·배당은 자동 복구하지 않는다. 기준 봉 누락은 보완하거나 만들어 넣지 않고 기존 검사로 중단한다.

원장이 보존되는 작은 수정, 반복 실행, 큰 수정, 운영 기준 이전 수정, 누락을 검사한다. 실제 서버 상태와 브라우저 검사를 별도로 확인한다.
